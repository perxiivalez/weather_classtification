# dataset/

ใส่รูปไว้ในโฟลเดอร์ย่อย 1 โฟลเดอร์ = 1 คลาส (ชื่อโฟลเดอร์ = ชื่อคลาส)

```
dataset/
  Cloudy/        Rain/        Shine/        Sunrise/        Storm Cloudy/
```

- เพิ่ม/ลบ/ย้ายรูปได้ตามต้องการ แล้วรัน `python train.py --final` ใหม่ (ระบบสร้าง cache ใหม่เองเมื่อรูปเปลี่ยน)
- เพิ่มคลาสใหม่ = สร้างโฟลเดอร์ใหม่ แล้วใส่รูป (จำนวนคลาสของโมเดลปรับเอง)
- มีโฟลเดอร์ย่อยซ้อนข้างในได้ (เช่นแยกตามแหล่งที่มา) ; รูปที่วางหลวมใน `dataset/` จะจับคลาสจากคำนำหน้าชื่อไฟล์ (rain12.jpg)
- ชื่อโฟลเดอร์สะกดต่างได้ผ่าน `aliases` ใน `classes.json` (เช่น rainy -> Rain)
- รองรับ jpg, jpeg, png, webp, bmp
